# MateClaw UI 光幕指挥舱主题设计

## 背景

`mateclaw-ui` 是化帆 AI 的后台工作台，不是营销站。它承载聊天控制台、AI 员工管理、技能市场、工作流、知识库、渠道、MCP、模型设置、安全审批和系统设置等高频运营页面。

当前主题偏暖棕、陶土和米色。参考图的方向是冷蓝光幕、细网格、玻璃卡片和高亮按钮。主题改造要吸收这套品牌气质，同时保留后台页面的可读性、信息密度和长期使用舒适度。

## 目标

把全站主题调整为“光幕指挥舱”：第一眼能识别出化帆 AI 的冷蓝科技感，实际使用时仍像一个可靠的 AI 员工运营后台。

成功标准：

- 全站从暖棕主题切换为冷蓝、冰白、深靛蓝的视觉体系。
- 首页、侧栏、聊天控制台、Dashboard 体现参考图的光幕、网格和玻璃质感。
- 设置、模型、MCP、知识库、安全审批等高密度页面保持清晰表格、表单和状态可读性。
- 移动端侧栏、首页、聊天页不出现文本重叠、按钮挤压或布局跳动。

## 推荐方向

采用“方案 A 光幕指挥舱”为主，“方案 B 冰原工作台”的可读性规则兜底。

光幕指挥舱负责品牌感：

- 深靛蓝到冰蓝的全局光幕背景。
- 极淡网格线和节点高光，呼应参考图。
- 深蓝玻璃侧栏，当前菜单使用亮蓝胶囊态。
- 半透明白蓝卡片和冷色描边。

冰原工作台负责可用性：

- 表格、表单、设置页以浅色高对比面板为主。
- 大面积内容区域减少渐变浓度。
- 状态色使用蓝、青、薄荷绿、琥珀、玫红，不让界面变成单一蓝色。
- 代码块、Markdown、图表、审批提示优先保证文字可读。

## 视觉系统

### 色彩

核心色：

- 主色：亮蓝 `#476CFF`
- 主色悬停：电光蓝 `#3455F4`
- 主色浅底：`rgba(71, 108, 255, 0.12)`
- 深背景：`#071442`
- 深侧栏：`rgba(8, 22, 66, 0.86)`
- 页面浅底：`#EEF6FF`
- 冰白卡片：`rgba(255, 255, 255, 0.78)`

辅助色：

- 青色用于连接、信息和 MCP：`#19BFD1`
- 薄荷绿用于健康、成功和在线：`#22C55E`
- 琥珀用于运行中、警告和待处理：`#F59E0B`
- 玫红用于失败、危险和审批阻断：`#EF476F`

### 背景

全局背景由三层组成：

1. 深靛蓝到冰蓝的斜向渐变。
2. 局部白蓝光带，模拟参考图右侧强光。
3. 极淡网格线和节点亮点，作为品牌纹理。

网格必须轻，不能抢占后台内容。设置、表格和聊天正文区域上方的容器要有足够不透明度，避免底纹影响阅读。

### 组件质感

- 主页面框架使用半透明玻璃面，边框为冷蓝或蓝紫色。
- 卡片圆角收敛在 12px 到 20px，避免营销页式大圆角。
- 按钮主态为亮蓝胶囊或 12px 圆角矩形；工具按钮继续使用图标按钮。
- 阴影改为冷色轻阴影，减少当前暖棕投影。

## 页面适配

### 全站壳层

文件：`mateclaw-ui/src/assets/main.css`、`mateclaw-ui/src/views/layout/MainLayout.vue`

- 替换全局 `--mc-*` token。
- 替换 body 和 `.app-layout` 背景。
- 保留现有左侧栏和主内容结构。
- 不恢复主题切换控件，沿用当前浅色默认逻辑。
- 移动端顶部栏使用浅玻璃面，菜单按钮保持高对比。

### 侧栏

侧栏是主题最重要的品牌信号：

- 背景改成深蓝玻璃。
- Logo 区增加冷蓝光晕。
- 导航分组标题用浅蓝灰。
- Hover 使用半透明蓝白。
- Active 使用亮蓝胶囊态，文字白色或高亮冰白。
- Footer 里的健康状态、语言切换和用户信息保持紧凑。

### 首页

文件：`mateclaw-ui/src/views/Home/index.vue`

首页承担主题样板作用：

- Banner 改成接近参考图的光幕横幅。
- 保留后台入口含义，不改成营销站。
- AI 员工卡片变成“员工能力卡”，使用半透明白蓝面板。
- 运行记录表格使用浅色可读底。

### 聊天控制台

文件：`mateclaw-ui/src/views/ChatConsole.vue`、`mateclaw-ui/src/components/chat/*`

- 会话侧栏偏深，和全站侧栏保持一致但略低对比。
- 聊天主区域使用浅冰白背景。
- 用户消息使用亮蓝渐变，助手消息使用白玻璃卡片。
- 输入框、模型选择器、审批提示和工具调用段落保持清楚边界。
- 流式状态、运行中任务、目标提示继续使用状态色，不全改蓝。

### Dashboard

文件：`mateclaw-ui/src/views/Dashboard.vue`

- 统计卡片使用冷蓝玻璃面。
- 主指标更亮，辅助指标更克制。
- 图表颜色读取新的 CSS token，使用蓝、青、绿、琥珀组合。
- 最近运行表格保持浅底、高对比和可横向滚动。

### 工作流、知识库、MCP 和设置

主要通过全局 token 继承主题：

- 工作流画布网格改成浅蓝点阵，节点选中态用亮蓝。
- 知识库和图谱面板使用白蓝卡片，避免图谱和底纹混在一起。
- MCP、模型、设置页以表单可读性优先，减少强光背景穿透。
- Markdown、代码块、表格继续使用高对比色。

## 非目标

- 不改路由、导航分组或信息架构。
- 不引入新的图标库或大型 UI 框架。
- 不恢复深色/系统主题切换。
- 不重写页面组件，只做主题和关键页面视觉适配。
- 不把后台改成营销落地页。

## 验证

实现后至少执行：

- `pnpm test -- appearancePreferences`
- `pnpm build`
- 浏览器检查首页、聊天控制台、Dashboard、设置模型页和安全审批页。
- 检查桌面和移动端宽度下的侧栏、卡片和按钮文字是否溢出。

如果构建失败，需要区分是主题改造引入的问题，还是仓库已有依赖或脚本问题。
